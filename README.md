Описание проекта

Биржевой брокер позволяет пользователям:

    Регистрироваться и аутентифицироваться в системе

    Управлять мультивалютным портфелем

    Покупать и продавать валюты по актуальным курсам

    Получать информацию о курсах валют в реальном времени

    Автоматически обновлять курсы через внешние API

Структура проекта

.
├── config.json                 # Конфигурация приложения
├── data/                       # Данные приложения
│   ├── exchange_rates.json     # Исторические данные курсов
│   ├── portfolios.json         # Портфели пользователей
│   ├── rates.json             # Текущие курсы валют
│   └── users.json             # Данные пользователей
├── logs/
│   └── valutatrade.log        # Логи приложения
├── main.py                    # Главный модуль
├── Makefile                   # Автоматизация задач
├── pyproject.toml             # Конфигурация Poetry
├── README.md                  # Документация
└── valutatrade_hub/           # Исходный код
    ├── cli/                   # Командный интерфейс
    │   ├── interface.py
    │   └── __init__.py
    ├── core/                  # Бизнес-логика
    │   ├── currencies.py      # Иерархия валют
    │   ├── exceptions.py      # Пользовательские исключения
    │   ├── models.py          # Модели данных
    │   ├── usecases.py        # Use Cases
    │   ├── utils.py           # Вспомогательные функции
    │   └── __init__.py
    ├── decorators.py          # Декораторы логирования
    ├── infra/                 # Инфраструктура
    │   ├── database.py        # Менеджер базы данных
    │   ├── settings.py        # Настройки приложения
    │   └── __init__.py
    ├── logging_config.py      # Конфигурация логирования
    ├── parser_service/        # Сервис парсинга курсов
    │   ├── api_clients.py     # API клиенты
    │   ├── config.py          # Конфигурация парсера
    │   ├── scheduler.py       # Планировщик обновлений
    │   ├── storage.py         # Хранилище курсов
    │   ├── updater.py         # Обновлятель курсов
    │   └── __init__.py
    └── __init__.py

Установка и запуск

Запустите приложение:

make project

Или 

poetry run project
